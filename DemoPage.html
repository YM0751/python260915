Start with the basics

웹의 세 가지 언어를 한 번에 익혀요.

HTML로 구조를 만들고, CSS로 꾸미고, JavaScript로 움직임을 더합니다. 아래 실습 화면의 값을 바꿔 보세요.

<h1> 구조 </h1>
.style { color: blue; }
button.onclick = 실행;
핵심 개념

역할은 다르지만 함께 작동합니다.

브라우저는 세 언어를 해석하여 우리가 보는 웹페이지를 만듭니다.

1

HTML: 구조

제목, 문단, 이미지, 버튼처럼 페이지에 들어갈 재료와 의미를 정합니다.

<button>클릭</button>
2

CSS: 표현

색상, 여백, 글꼴, 배치, 화면 크기에 따른 반응형 디자인을 담당합니다.

button { color: white; }
3

JavaScript: 동작

클릭, 입력, 계산, 데이터 변경처럼 사용자와 상호작용하는 기능을 만듭니다.

button.addEventListener(...)
직접 실습

나만의 카드 만들기

입력값이 바뀌면 JavaScript가 미리보기 화면의 HTML을 변경합니다.

Tip: 개발자 도구(F12)의 Console에서 JavaScript 결과도 확인해 보세요.

오늘의 학습

작은 변경도 페이지의 모습을 바꿉니다.
